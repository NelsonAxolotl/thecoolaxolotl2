## 🛠️ Technologies

- React
- Vite
- JavaScript
- CSS
- Git & GitHub
- Vercel

---

## 🚀 Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 📦 Production

Build the project:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Production files are generated in the `dist/` directory.

---

## 🌐 Deployment
